# Focused expansion plan (private)

Grow only where there is real eligibility and genuinely useful local content. No templated city or state pages.

1. **Resource articles first.** Use /admin/resources for in-depth single-topic articles that answer questions sellers already ask you (for example: "What a Washington seller pays at closing on an as-is sale," "How assignment works, with a sample timeline"). Add a real author and reviewer only when they exist.
2. **A second state page only when:** the state is approved in /admin/states after a documented rules review; you can write material specific to that state (taxes, disclosure law, closing customs, foreclosure process, any wholesaler rules) with sources; and you can actually complete transactions there. Then add a route like `/service-areas/oregon`, set its page path in /admin/states, and the map links to it automatically.
3. **Local Washington pages** (for example a Pierce County page) only with distinct local value: county excise rates, local market observations you can support, and real experience there.
4. **Proof modules** (testimonials, closed-deal stories, statistics) only with real, verifiable content and permission. Leave them out until then.
5. **Investor opportunities:** if you later want an opt-in, login-protected deal feed, build it behind authentication with explicit seller permission. Don't publish inventory publicly.
